資料來源與注意事項

資料由 GitHub Actions 透過 TDX 產生，屬於預定時刻表，非即時誤點／停駛資訊。票價採成人單程票，高鐵為標準車廂對號座；台鐵依車種比對。未能可靠對應的票價顯示「待確認」，不會任意估算。網站只讀取與所選日期相同的 JSON；未發布日期不會以其他日期班次替代。午夜跨日轉乘需另外核對次日班次。自動推薦僅使用已發布日期內的班次，且不考慮即時誤點、月台距離變動與額外轉乘交通工具。
